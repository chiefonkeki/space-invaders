# VaporInvaders 👾📼

A retro 1980s vaporwave **Space Invaders arcade game** with an integrated real-time **Synthwave Cassette Player** vibe-coded through **Google AI Studio** built with React, Tailwind CSS, and the Web Audio API.

---

## 🎮 How to Play

### Controls
| Action | Keyboard | Mobile |
| :--- | :--- | :--- |
| **Move** | `A` / `D` or `Arrow Keys` | Left / Right On-screen Buttons |
| **Shoot** | `Spacebar` or `W` | On-screen FIRE Button |
| **Pause** | `P` or `Escape` | Tap Pause |

### Scoring
- **Squid**: 30 pts
- **Crab**: 20 pts
- **Octopus**: 10 pts
- **Mystery UFO**: 50 – 300 pts

---

## 📼 Cassette Soundtrack

All music and sound effects are generated procedurally in the browser using the Web Audio API (no external audio files needed):

1. **Neon Highway 1984** (104 BPM · Outrun Synthwave)
2. **Cyber City Drift** (120 BPM · Electro Darksynth)
3. **Midnight Cassette Dreams** (88 BPM · Chill Vaporwave)

Features real-time audio visualization (Neon Bars & Oscilloscope waveform), volume slider, track selection, and spinning cassette reels.

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
